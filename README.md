# STOCKMIND

Graham-Based Stock Analysis and
Machine Learning Web Application.

## Features

- SET100 Stock Screening
- Graham Number Valuation
- Margin of Safety Analysis
- Investment Screening Signals
- Experimental ML Predictions
- Stock Comparison
- Model Performance Dashboard

## Run Application

pip install -r requirements.txt

streamlit run app.py

## Disclaimer

This application is an academic prototype.
It is not personalized investment advice.
